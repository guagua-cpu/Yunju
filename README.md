# 云居 · 最有温度的家装行业数字化服务商

当前第三版功能、验证和交付边界见 [第三版说明](FEATURES-v3.md)。第二版见 [第二版记录](FEATURES-v2.md)。以下第一版说明保留作历史参考。

## 本地运行

在本目录运行静态 HTTP 服务，将 dist 作为站点目录；访问首页。

## 已实现

- 奶白、米白、浅紫配色，响应式侧栏、任务入口、素材卡片和编辑工作区。
- 五种角色工作台：业主、设计师、材料商、施工方、监理。
- 三维空间嵌入 BoHack_1。模块来自 D:/Desktop/BoHack_1/floorplan-3d，原始文件未修改。
- 仅在副本引入 yunju-theme.css，保留原模块 JavaScript、几何、存储与 Three.js 场景背景。
- 商品搜索、分类、房间、交期筛选、收藏、三项对比及方案选品。
- 本地属性线性模型增量学习、探索推荐、选择概率记录；反馈撤销后重算。不是多用户生产训练系统。
- 偏好确认、删除、暂停、恢复上一步和学习记录。
- 项目任务前置关系、需求/变更/验收/售后本地登记。
- 预算与角色费用视图、导出、目标预算调整。
- 图片预留和素材清单页面。

## 功能边界

- 所有业务数据是演示数据，保存在当前浏览器 localStorage。
- 角色切换不是后端身份验证，不具备真实数据权限隔离。
- 未接入真实支付、签约、消息发送、多人同步或大语言模型。
- 三维模块内部工程量与平台商品清单尚未自动同步。
- 三维模块首次加载依赖 jsDelivr 的 Three.js r160 模块；需联网。
- 已生成推荐批次不等于有效可见曝光，生产接入需补可见曝光、延迟反馈和评估。
- 费用估算含示例基础项；选品按一单位演示，不能作为正式成交报价。
